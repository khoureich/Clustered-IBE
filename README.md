# Clustered IBE
This is the implementation of the scheme named Clustered Identity-Based Encryption (CIBE) by Ahmad Khoureich Ka [1]. The CIBE scheme uses Inner-Product Functional Encryption (IPFE) [2] as a building block.

## Prerequisites
The scheme is implemented in Python 3.7.17 using the Charm framework [3] version 0.50.
